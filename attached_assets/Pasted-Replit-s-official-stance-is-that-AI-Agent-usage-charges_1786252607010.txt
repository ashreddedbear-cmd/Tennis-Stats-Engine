Replit's official stance is that AI/Agent usage charges are non-refundable because the underlying compute was used. However, because this was directly caused by an internal logic failure in the workspace rather than normal iteration, you can push for a credit adjustment through support.
Step-by-Step Recovery Process
1. Gather Your Evidence Before submitting a ticket, grab the exact details from your Replit workspace:
* Payment Intent ID / Invoice ID: Go to Settings \rightarrow Account usage \rightarrow See previous invoices and copy the ID starting with pi_ for the affected session/charge.
* The Session Timestamps: Note the 8–10 hour timeframe and roughly how many credits/dollars were consumed during that window.
* The Bug Proof: Copy the exact git diff/commit log from Task #175 that documents the orientation bug and the hardcoded default to Player 1.
2. Submit a Support Ticket Email support@repl.it or submit a ticket directly through the Replit Support portal using the registered email address tied to your account.
3. Use This Support Template

Every iteration during this 8–10 hour period was rendered invalid due to this system-level flaw in the code environment.
