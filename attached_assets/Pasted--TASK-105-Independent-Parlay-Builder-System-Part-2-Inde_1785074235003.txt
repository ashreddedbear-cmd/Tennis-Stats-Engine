# TASK 105 – Independent Parlay Builder System (Part 2)

## Independent Validation Sources

The Independent Parlay Builder must validate every prediction using multiple independent evidence sources.

No single source may determine whether a leg is kept or removed.

Each source contributes its own weighted score.

Each source must be implemented as an independent adapter/service so it can be enabled, disabled, upgraded, or replaced without changing the Prediction Engine.

Failure of one source must never stop Builder scoring.

---

# Source 1 – Tennis Abstract

This is the primary statistical validation source.

Collect whenever available:

• Overall Elo

• Surface Elo

• Elo Difference

• Recent Elo Trend

• Last 10 Matches

• Surface Match History

• Hold %

• Break %

• Ace %

• Double Fault %

• First Serve %

• Second Serve %

• Return Points Won

• Tiebreak Record

• Opponent Quality

• Historical Consistency

• Surface Consistency

• Historical Volatility

• Historical Retirement Rate

• Head-to-Head

Missing Tennis Abstract data must NEVER automatically remove a leg.

Instead:

• Reduce data coverage

• Lower confidence

• Display "Limited Tennis Abstract Coverage"

For lower-level events.

• Retirements

• Withdrawals

ITF data should help validate lower-ranked players where ATP/WTA coverage is limited.

---

# Source 6 – Market Consensus

Use authorized odds providers when available.

Examples include:

• Pinnacle

• Betfair Exchange

• Other approved sharp-market providers

Collect:

• Opening Odds

• Current Odds

• Closing Odds (when available)

• Implied Probability

• Market Movement

• Consensus Probability

• Reverse Line Movement

• Late Steam

Builder should compare market consensus with statistical evidence.

Market disagreement should reduce Validation Score.

Market agreement should increase confidence.

Markets must NEVER become the final decision maker.

# Source Agreement Engine

After all adapters complete:

Calculate:

Number of sources supporting selected player

Number of sources supporting opponent

Number of missing sources

Number of conflicting sources

Number of stale sources

Calculate a Source Agreement Score.

Example:

Tennis Abstract ✓

UTR ✓

ATP ✓

Recent Form ✓

Market ✓

Head-to-Head ✗

Agreement:

5 of 6 sources

Agreement should increase Validation Score.

Major disagreement should increase Risk Score.

Missing data should reduce Data Coverage but should not automatically remove the leg.
