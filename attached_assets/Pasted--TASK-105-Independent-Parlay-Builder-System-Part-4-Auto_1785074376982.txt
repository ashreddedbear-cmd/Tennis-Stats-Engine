# TASK 105 – Independent Parlay Builder System (Part 4)

# Auto Parlay Builder

The Auto Builder must operate independently from the Prediction Engine.

It may only use Builder results.

Never use Engine Confidence, Engine Recommendation, or Engine Probability when selecting legs.

---

# Auto Build Options

Create the following builder modes:

• Best 3

• Best 5

• Best 8

• Best 10

• Highest Validation

• Lowest Risk

• Highest Reliability

• Highest Stability

• Highest Source Agreement

• Lowest Volatility

---

# Auto Build Rules

Default rules:

Only KEEP legs are eligible.

Never include REMOVE legs.

BORDERLINE legs may only be included if enabled by the administrator.

Do not duplicate the same match.

Do not include duplicate players.

Avoid correlated risk whenever possible.

Warn when several selections come from the same tournament.

Warn when several selections depend heavily on one external source.

---

# Rescoring

Allow old sessions to be rescored using newer Builder configurations.

Never overwrite historical results.

Instead:

Original Score → Version 1

New Score → Version 2

Store both.

---

# Builder Independence Test

Verify:

Changing Builder weights

MUST NOT

change Prediction Engine outputs.

Changing Prediction Engine calibration

MUST NOT

change Builder Validation Scores.

Prediction Engine and Builder must remain permanently isolated.

---

# Acceptance Criteria

Task 105 is complete only if:

✓ Builder uses only Builder scoring.

✓ Prediction Engine remains untouched.

✓ Builder validates using Tennis Abstract, UTR, ATP, WTA, ITF, Recent Form, Surface Analysis, Head-to-Head, Market Consensus, Injuries, and Travel/Fatigue.

✓ KEEP/REMOVE decisions are fully independent.

✓ Every decision includes evidence-based reasons.

✓ Auto Builder never uses Prediction Engine confidence.

✓ Builder sessions are stored separately.

✓ Builder can evolve without modifying the Prediction Engine.
