REFERENCE CASE: WTA Toronto, Kostyuk vs Swiatek. Raw signals (Elo, Serve/Return, Recent Form, Market Consensus) all favored Swiatek at roughly 63%. Isotonic calibration reversed this to ~84% Kostyuk. The WTA-Hard Specialist Model hit its weight ceiling of 0.85, leaving all four disagreeing raw signals fighting over the remaining 15% combined. Confidence engine passed this as HIGH CONFIDENCE because margin was 14 points and Specialist/General "agreed" — but that agreement only existed because both were fed the same already-flipped calibrated number. Swiatek won the actual match.

THE PROBLEM, IN TWO PARTS:

PART A — SPECIALIST WEIGHT CEILING IS TOO PERMISSIVE
The current formula allows a specialist model to reach 0.85 effective weight, which in practice silences the combined voice of every other signal when they disagree.

PART B — CALIBRATION HAS NO SANITY CHECK AND MAY BE OVERFIT
The isotonic calibration is applied to the raw ensemble with zero safeguard. Given how large this reversal was (63% one way to 84% the other), this pattern should be treated as a signal of likely overfitting until proven otherwise, not accepted as gospel.

STEP 0 — EMPIRICAL BACKTEST (DO THIS FIRST, BEFORE ITEM 1)
Before choosing any new specialist weight ceiling or any new override rule, query the historical WTA-Hard match data:

For every past graded WTA-Hard match where all four raw signals unanimously favored the same player AND the specialist favored the other player — record which side actually won.

Report:
- Total number of such true-disagreement cases
- Win rate for the specialist's pick in those cases
- Win rate for the raw-consensus pick in those cases
- If fewer than ~30 such cases exist, say so explicitly and treat the result as directionally suggestive only — do not let a small sample drive a hard rule, for the same reason the calibration reversal itself is suspect.

This result determines how aggressive items 1 and its addendum below should actually be. Do not skip this — shipping a new hard-coded rule without checking it against the 9,408 matches you already have would repeat the exact mistake we're trying to fix.

   Report the exact line/file where this constant lives and confirm the change made.

   - If STEP 0 shows raw consensus outperforms (or is statistically indistinguishable from) the specialist: apply this rule — a specialist must demonstrate BOTH good calibration AND better-than-general pick accuracy to earn elevated influence over a unanimous vote.
