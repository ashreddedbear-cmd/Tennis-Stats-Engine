**Root cause of the admin-access problem (explains 3 of your 4 symptoms):**

Everything admin-related in this app — the shield badges, the "Admin" button on Payments, access to Model Monitoring/Launch Audit/Admin Users/etc. — all hinges on one thing: `adminAuth?.authenticated` from `useGetAdminAuthStatus()`. When that's false, shields disappear, admin buttons disappear, and admin-gated pages redirect you straight to the login screen you screenshotted. That's one root cause producing three symptoms, not three separate bugs.

Digging into the auth history, I found this sequence, all in about 90 seconds on July 25:
- `c75a23f` (03:11am) — added an **owner auto-login route**: a bookmarkable URL with a token (`/auth/owner-auto-login?token=...`) that sets your admin session cookie directly, no login form needed.
- `1e4b888` (03:15am) — added an alternate auto-auth path based on Replit identity headers (`x-replit-user-id`).
- `2b9a22a` (03:16am) — **removed the token-based auto-login route entirely**, leaving only the Replit-header method.

The Replit-header method only works when `OWNER_REPLIT_AUTO_AUTH=true` is set *and* the request carries Replit's own identity headers — which happens inside Replit's preview iframe, but likely **not** when you hit the public `.replit.dev` URL directly from Safari on your phone, which is exactly what your screenshot shows. If you had a bookmarked auto-login link, it stopped working the moment `2b9a22a` landed, and you'd have been thrown back to the manual sign-in screen ever since — with every admin shield across the app gone because they're all downstream of that same `isAdmin` flag.

**The logo issue is unrelated** — a separate, simpler bug: the app actually has *two* logo assets that were never kept in sync. `TennisMatrixLogo.tsx` (the real in-app logo) went through five design revisions, including one explicitly called *"completely redesign Tennis Matrix logo — professional green racket with ball."* But the sign-in screen you screenshotted doesn't use that component — it uses a static `public/logo.svg` file that Clerk reads directly, and that file was **committed exactly once, and never touched again**. So the sign-in screen is showing the old pre-redesign logo while the rest of the app shows the new one.
