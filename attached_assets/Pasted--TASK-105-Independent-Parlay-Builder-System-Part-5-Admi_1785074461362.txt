# TASK 105 – Independent Parlay Builder System (Part 5)

This panel must be completely separate from the Prediction Engine settings.

Changing Builder settings must NEVER affect Prediction Engine predictions.

# Automated Testing

Verify:

✓ Builder cannot write to Prediction Engine.

✓ Builder scores never reference Engine Confidence.

✓ Builder scores never reference Engine Probability.

✓ Builder scores never reference Engine Recommendation.

✓ Prediction Engine predictions remain identical after Builder changes.

✓ Builder configuration changes only affect Builder outputs.

✓ Missing validation sources reduce confidence without crashing Builder.

✓ Historical sessions remain unchanged after new Builder versions are released.

---

# Final Rule

The Prediction Engine and Independent Parlay Builder are permanently separate systems.

Prediction Engine:

Predicts winners.

Parlay Builder:

Determines whether those predicted winners are suitable for inclusion in a parlay.

Neither system may influence, modify, retrain, calibrate, or score the other.

They communicate only through a read-only Builder Snapshot.

This separation is a permanent architectural requirement and must never be violated.
